01

LangGraph Agent Workflows

Case Study

The Problem

Modern agentic systems require reliable, multi-step execution. Standard LLM chains lack explicit state boundaries, making cyclic operations, conditional routing, and secure tool usage difficult to maintain and debug reliably.

The Approach

Adopted LangGraph to construct directed cyclical graphs. This enforced strict state typing at every node transition, allowing safe tool orchestration (via Model Context Protocol concepts) and deterministic logic routing.

Technical Decisions

Why LangGraph over standard chains?

Standard chains are linear. LangGraph permits cycles, which are strictly required for an agent to evaluate its own output, decide if more context is needed, route to a tool, and re-evaluate before finishing.

State Management

By enforcing an explicit typed state dictionary, any node in the graph can reliably append or overwrite specific keys, preventing context leakage between unrelated workflow branches.

02

Shelf Product Identifier

Case Study

The Problem

In retail analytics, manual stock estimation and planogram compliance checks are highly inefficient. The system needed to automatically detect and classify closely-packed products in high-density, unstructured shelf imagery.

The Approach

Built a decoupled pipeline. First, YOLO localizes product boundaries irrespective of brand. Second, bounded regions are cropped and passed to a ResNet18 feature-extraction stage for SKU matching. The repository documents a saved sample run and the evaluation still needed for generalizable performance claims.

Technical Decisions

Why decouple Localization and Classification?

Single-shot detectors struggle when classes number in the thousands with minimal visual variance (e.g., different flavors of the same brand). Decoupling allows YOLO to excel at drawing boxes, while a deeper CNN (ResNet18) focuses entirely on distinguishing fine-grained features from isolated crops.

Data Processing

OpenCV handles ingestion and normalization, while Pandas is utilized post-inference to map array outputs into structured, analyzable planogram matrices.
